# 📱 Tarjeta de Presentación Interactiva con Flutter

Una aplicación desarrollada con **Flutter** y **Material 3** que simula una tarjeta de presentación digital e interactiva. Este proyecto fue creado con el objetivo de aprender los fundamentos del desarrollo de aplicaciones multiplataforma utilizando Flutter.

## ✨ Características

- 👤 Tarjeta de presentación moderna.
- 📷 Imagen de perfil.
- 📝 Nombre y profesión.
- 📧 Información de contacto.
- 📍 Ubicación.
- 💻 Enlace a GitHub.
- ❤️ Botón de favorito.
- 🌙 Cambio entre modo claro y modo oscuro.
- ✨ Animaciones con `AnimatedContainer`.
- 📱 Diseño adaptable para dispositivos móviles y web.
- 🎨 Interfaz basada en Material 3.

## 🚀 Cómo ejecutar el proyecto

### 1. Clonar el repositorio

```bash
git clone https://github.com/93Cast/NOMBRE_DEL_REPOSITORIO.git
```

### 2. Entrar al proyecto

```bash
cd NOMBRE_DEL_REPOSITORIO
```

### 3. Instalar dependencias

```bash
flutter pub get
```

### 4. Ejecutar la aplicación

```bash
flutter run
```

También puedes ejecutar el proyecto en plataformas específicas:

```bash
flutter run -d chrome
```

```bash
flutter run -d windows
```

```bash
flutter run -d android
```
